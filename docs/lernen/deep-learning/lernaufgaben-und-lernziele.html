Wie wird aus einer Aufgabe ein Lernproblem?

Beim Deep Learning lernt ein neuronales Netz in mehreren Schichten Darstellungen für seine Aufgabe. Beim überwachten Lernen (supervised learning) besteht ein Trainingsbeispiel aus einer numerisch dargestellten Eingabe x und einem bekannten Zielwert y (target). Die Vorhersage des Netzes heißt ŷ. Ein Zielwert kann etwa die gemessene Dauer eines Vorgangs oder die bekannte Produktkategorie sein.

Definiere zuerst, welche Eingaben zum Zeitpunkt der Vorhersage verfügbar sind und was der Zielwert fachlich bedeutet. Eine Kategorie aus einer nachträglichen Prüfung kann ein geeignetes Ziel sein. Ihr Ergebnis als Eingabemerkmal zu verwenden würde die Vorhersageaufgabe verändern.

Welche Ausgabe passt zur Aufgabe?

Regression (regression)
Das Ziel ist eine numerische Größe, etwa eine Dauer in Sekunden. Eine lineare Ausgabe eignet sich für einen unbeschränkten reellen Wert. Bei einem fachlich eingeschränkten Wertebereich prüfst du, ob Ausgabe oder Modellierung diesen Bereich berücksichtigen sollten. Ein typischer Verlust ist der mittlere quadratische Fehler (mean squared error, MSE).
Binäre Klassifikation (binary classification)
Das Ziel ist 0 oder 1. Eine Sigmoidfunktion wandelt eine Rohbewertung (logit) in einen Wert zwischen 0 und 1 um. Dazu passt die binäre Kreuzentropie (binary cross-entropy). Aus dem Wahrscheinlichkeitswert wird anhand einer Schwelle eine Entscheidung.
Mehrklassen-Klassifikation (multiclass classification)
Genau eine von mehreren Klassen trifft zu. Die Softmaxfunktion wandelt die Logits in Klassenwahrscheinlichkeiten um, die sich zu eins addieren. Die Kreuzentropie (cross-entropy) bewertet die Wahrscheinlichkeitsverteilung anhand der Zielklasse.
Mehrfachzuordnung (multilabel classification)
Mehrere Kennzeichnungen (labels) können gleichzeitig zutreffen. Verwende beispielsweise einen Sigmoidwert und eine binäre Kreuzentropie pro Label. Die Ausgabewerte müssen sich dann nicht zu eins addieren.

Wie macht der Verlust einen Fehler messbar?

Die Verlustfunktion (loss function) gibt dem Training eine Zahl, die sich minimieren lässt. Der MSE über n Beispiele mit je einem Zielwert ist ein solches Maß.

MSE=1n∑i(ŷi−yi)2

Der Index i läuft über die Beispiele. Du quadrierst die Abweichung von Vorhersage und Ziel und bildest den Mittelwert. Eine doppelt so große Abweichung trägt viermal so stark bei.

Bei genau einer richtigen Klasse ist die Kreuzentropie eines Beispiels −log(pc). Dabei ist pc die vorhergesagte Wahrscheinlichkeit der richtigen Klasse c. Je kleiner diese Wahrscheinlichkeit ausfällt, desto größer wird der Verlust, selbst wenn die vorhergesagte Klasse unverändert bleibt.

Merksätze

  • Die fachliche Bedeutung der Zielwerte bestimmt die Form der Ausgabe.
  • Softmax passt zu genau einer Klasse. Einzelne Sigmoidwerte erlauben gleichzeitig zutreffende Labels.
  • Der Verlust legt fest, wie stark verschiedene Vorhersagefehler in das Training eingehen.

Verständnisfrage

Ein Foto kann gleichzeitig die Labels „Nacht“ und „Regen“ tragen. Welche Ausgabe und welcher Verlust passen dazu?

Musterantwort

Für jedes Label passt ein Sigmoidwert mit binärer Kreuzentropie. Damit können beide Labels hohe Werte erhalten. Softmax würde Wahrscheinlichkeitsmasse auf die Klassen verteilen, obwohl beide Labels gleichzeitig zutreffen können.
