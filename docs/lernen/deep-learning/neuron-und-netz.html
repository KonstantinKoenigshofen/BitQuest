Was berechnet ein künstliches Neuron?

Ein künstliches Neuron (artificial neuron) multipliziert jede seiner Eingaben xi mit einem Gewicht (weight) wi. Es summiert die Beiträge und addiert einen lernbaren Offset, den Bias b. Auf diese Zwischengröße z wendet es eine Aktivierungsfunktion (activation function) f an. Das Ergebnis ist seine Ausgabe a.

z=∑iwixi+b,a=f(z)

Der Index i bezeichnet die jeweilige Eingabekomponente. Die Gewichte beeinflussen, wie stark eine Eingabe die Summe erhöht oder senkt. Der Bias verschiebt die Summe unabhängig von den aktuellen Eingabewerten. So kann etwa eine Aktivierungsschwelle an einer anderen Stelle liegen als beim Ursprung.

Warum brauchen tiefe Netze Nichtlinearität?

Eine gewichtete Summe plus Bias ist eine affine Abbildung (affine transformation). Würde jede Schicht nur solche Abbildungen berechnen, ließe sich die Verkettung zu einer einzigen affinen Abbildung zusammenfassen. Zusätzliche Schichten würden die damit darstellbaren Funktionen nicht erweitern.

Eine nichtlineare Funktion wie ReLU (rectified linear unit) gibt negative Zwischengrößen als null aus und nimmt bei positiven Zwischengrößen den Wert unverändert an. So können nächste Schichten abhängig von der Eingabe verschiedene Merkmale kombinieren. Ein Netz kann dadurch etwa Bereiche mit geknickten statt nur geraden Entscheidungsgrenzen bilden.

Die Sigmoidfunktion begrenzt die Ausgabe auf Werte zwischen null und eins. In verdeckten Schichten können ihre Ableitungen bei großen positiven oder negativen Eingaben sehr klein werden. Welche Funktion du wählst, beeinflusst damit sowohl die Darstellung als auch den Lernprozess.

Wie entsteht aus vielen Neuronen eine Vorhersage?

In einem vorwärts gerichteten Netz (feedforward network) fließen Werte von den Eingaben durch die verdeckten Schichten (hidden layers) zur Ausgabeschicht (output layer). Eine vollständig verbundene Schicht (fully connected layer) berechnet für mehrere Neuronen gleichzeitig gewichtete Summen mit einer Matrix von Gewichten. Jede Zeile enthält die Gewichte eines Neurons zur vorherigen Schicht.

Beim Vorwärtsdurchlauf (forward pass) wird die Ausgabe einer Schicht zur Eingabe der nächsten. Jede Schicht kann eine neue Darstellung erzeugen. Die letzte liefert die Vorhersage. Das Training verwendet dieselbe Vorwärtsrechnung, um den Verlust zu bestimmen. Bei der Anwendung des trainierten Netzes heißt die Vorhersage Inferenz (inference).

Merksätze

  • Ein Neuron verbindet Eingaben über Gewichte, verschiebt die Summe über den Bias und wendet seine Aktivierungsfunktion an.
  • Nichtlineare Aktivierungen ermöglichen Funktionen, die eine einzelne affine Schicht nicht darstellen kann.
  • Der Forward Pass berechnet die Vorhersage schichtweise mit den aktuellen Parametern.

Verständnisfrage

Zwei vollständig verbundene Schichten rechnen nur gewichtete Summen plus Bias. Was ändert sich, wenn du zwischen ihnen ReLU einfügst?

Musterantwort

Ohne ReLU lassen sich beide Schichten zu einer affinen Abbildung zusammenfassen. Mit ReLU wird abhängig von der Eingabe ein Teil der Zwischenausgaben auf null gesetzt. Die zweite Schicht kann deshalb in verschiedenen Eingabebereichen unterschiedliche Beiträge kombinieren.
