Wie machst du numerische Daten vergleichbar?

Numerische Merkmale (features) können sehr verschiedene Einheiten und Größenordnungen haben. Eine Standardisierung (standardization) zieht je Merkmal den Mittelwert ab und teilt durch die Standardabweichung. So haben die transformierten Trainingswerte typischerweise Mittelwert null und Standardabweichung eins. Das kann dem Optimierer helfen, mit Merkmalen auf ähnlicher Skala zu arbeiten. Bei konstanten Merkmalen geht die Division durch null, deshalb musst du sie gesondert behandeln.

Eine Min-Max-Skalierung (min-max scaling) bildet anhand eines Minimums und Maximums auf einen Zielbereich ab. Einzelne Extremwerte können die übrigen Beobachtungen darin zusammendrängen. Wähle die Transformation passend zu Verteilung und Aufgabe. Schätze ihre Parameter nur auf Trainingsdaten und verwende sie anschließend unverändert für Validierung, Test und Inferenz. Wie stellst du Kategorien und Wörter dar?

Eine beliebige Nummer pro Kategorie kann eine ungewollte Reihenfolge und Abstände einführen. Bei der One-Hot-Kodierung (one-hot encoding) steht jede Kategorie für eine eigene Position im Vektor. Für die beobachtete Kategorie ist dort eine Eins gesetzt. Dieses Verfahren eignet sich für eine überschaubare Anzahl ungeordneter Kategorien.

Ein Embedding ist hier ein gelernter dichter Vektor. Kategorien oder Wörter können darüber in weniger Dimensionen dargestellt werden als bei One-Hot. Bei Word2Vec liefern Wortkontexte das Lernsignal. Die Variante Skip-gram nutzt ein Wort, um Wörter in seiner Umgebung vorherzusagen. Nach dem Training kannst du die gelernten Vektoren für weitere Aufgaben verwenden. Ähnliche Kontexte können ähnliche Vektoren ergeben. Ein Word2Vec-Vektor fasst dabei die verschiedenen Verwendungen eines Wortes in einer Darstellung zusammen.

Was misst der Winkel zwischen zwei Vektoren?

Die Kosinusähnlichkeit (cosine similarity) vergleicht die Richtungen zweier von null verschiedener Vektoren u und v. Im Zähler steht das Skalarprodukt und im Nenner das Produkt ihrer euklidischen Längen.

cos(φ)=u⋅v‖u‖‖v‖

φ ist der Winkel zwischen den Vektoren. Gleiche Richtung ergibt eins, ein rechter Winkel null und entgegengesetzte Richtung minus eins. Hohe Ähnlichkeit zeigt eine ähnliche Richtung in der gelernten Darstellung. Welche fachliche Bedeutung das hat, hängt von den Trainingsdaten und der Lernaufgabe ab.

Wann ist eine kompaktere Darstellung sinnvoll?

Die Hauptkomponentenanalyse (principal component analysis, PCA) projiziert die Daten linear auf Richtungen, in denen sie am stärksten streuen. Mit weniger Komponenten erhältst du eine kompaktere Darstellung. Kleine Varianz kann trotzdem ein wichtiges Signal für die spätere Zielgröße enthalten. Miss daher den Nutzen anhand dieser Aufgabe und passe PCA nur an die Trainingsdaten an.

Ein Autoencoder trainiert einen Encoder, der die Eingabe in einen Code überführt, und einen Decoder, der daraus die Eingabe rekonstruiert. Die Eingabe liefert dabei selbst den Zielwert. Ein enger Zwischenraum (bottleneck) zwingt das Netz, für die Rekonstruktion wichtige Informationen zu verdichten. Ein niedriger Rekonstruktionsfehler sagt noch wenig darüber aus, ob der Code die Merkmale enthält, die du für eine spätere Klassifikation brauchst.

Merksätze

  • Skalierung und Kodierung beeinflussen, welche Unterschiede ein Modell in den Eingaben vorfindet.
  • Ein Embedding lernt eine Darstellung aus einer Aufgabe. Kosinusähnlichkeit vergleicht darin Richtungen.
  • PCA bewahrt vor allem Varianz. Ein Autoencoder lernt für die Rekonstruktion. Prüfe die Darstellung an ihrem späteren Zweck.

Verständnisfrage

Ein Autoencoder rekonstruiert Sensordaten gut. Warum kann sein kompakter Code trotzdem für die Erkennung seltener Defekte ungeeignet sein?

Musterantwort

Der Rekonstruktionsverlust gewichtet die häufigen Muster stark, wenn sie die meisten Daten ausmachen. Ein seltenes, für Defekte wichtiges Merkmal kann im Code fehlen, obwohl die meisten Eingaben gut rekonstruiert werden. Prüfe mit separaten Defektbeispielen, ob die Darstellung diese Unterschiede bewahrt.
